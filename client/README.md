# Client (React + Tailwind)

Quick start:

1. Change to the client folder:

```bash
cd client
```

2. Install dependencies:

```bash
npm install
```

3. Run dev server:

```bash
npm run dev
```

The frontend expects the backend API at `http://localhost:3000` by default. You can change it by setting `VITE_API_URL` in a `.env` file inside `client/`.
